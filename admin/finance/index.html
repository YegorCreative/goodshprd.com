Understand these figures

Revenue includes completed and paid sales before refunds. Collected includes successful payments only. Estimated profit = Revenue − Refunds − known Cost of Goods − Expenses. Unknown costs are flagged, and processing fees must be entered as expenses. Order totals include any tax and shipping. Sales, payments, refunds, and expenses each use their own dates. Each currency is reported separately.

Comparisons use the preceding period with the same number of days. Percentage changes are omitted when the previous value is zero or negative. Chart data is aggregated on the server; longer overview ranges use monthly buckets.
